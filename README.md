# Household Magic for Pathfinder 2e

Ever found it weird that you need take an entire cantrip slot just to be able to magically ignite a candle or that you, as a wizard, can't really do any basic mundaine magic whie being able to cast extremely powerful spells? 

Household Magic fixes this by taking weaker or rarely used cantrips and just... allowing anybody with Cast a Spell activity to use them. No restrictions, no cantrip slots wasted.

Household Magic is a free bonus feat that all magic users can take. This feat allows to cast the following cantrips for free and without affecting the cantrip limit:
- Prestidigitation
- Approximate
- Illuminate
- Sigil
- Time Sense
- Glamorize
- Simple Illusion

Household Magic also includes a new *Simple Illusion* cantrip which, as the name suggests, allows to create basic illusions.

*Balance considerations:* This rule doesn't really affect the balance or make casters any stronger. All +1 bonuses from the cantrips are removed and the cantrips included in Household Magic
are mostly there to make roleplaying as a magic user more fun and interesting without taking up valuable cantrip slots.

## Installation

1. In your Foundry VTT, go to `Setup -> Modules -> Install Module`
2. In the `Manifest URL` textbox paste:

```
https://github.com/Martenfur/pf2e-household-magic/releases/latest/download/module.json
```

3. Enable the `Household Magic` module in your world.
4. In Bonus Feats of your character, search `Household Magic` and add it as a bonus feat!
5. Create a new spell entry and add the cantrips listed in the feat.

## Compatibility

Tested on Foundry 14, but should work with future and probably past releases too.
